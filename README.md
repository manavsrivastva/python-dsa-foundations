# Python DSA Foundations — Practice Portfolio

A beginner-friendly collection of Python implementations for core Data Structures and Algorithms.

## Topics
- Big-O time and auxiliary-space complexity
- Lists/arrays and string manipulation
- Two pointers
- Linear and binary search
- Bubble, selection, insertion sort; built-in `sorted()` and sort keys
- Dictionaries, sets, frequency counting, two-sum, duplicates, anagram grouping
- Stacks and queues (`list`, `collections.deque`)
- Singly linked lists
- Recursion: factorial, Fibonacci, sum of digits
- Regression tests using `unittest`

## Run
Python 3.10+ recommended. No third-party dependencies.

```powershell
python main.py
python -m unittest discover -s tests -v
```

Read each function and its complexity comments before presenting this portfolio. Be ready to explain why each algorithm works and its trade-offs.
